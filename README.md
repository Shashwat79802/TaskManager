## Setup
1. Create & activate virtualenv:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Start the server:
   ```bash
   python manage.py runserver
   ```
4. Run tests:
   ```bash
   python manage.py test task
   ```

Docs available at: http://localhost:8000/docs/
